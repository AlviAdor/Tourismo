# Tourismo

A Java-based desktop application developed using **Object-Oriented Programming (OOP)** principles and a graphical user interface. The project provides a structured application flow with user authentication, registration, a homepage interface, and multiple article sections.

The application starts with a **login interface**, allowing users to authenticate before accessing the main application. New users can register through the dedicated registration module, while authenticated users can navigate through the homepage and access different articles.

## Features

- **User Login** – Authentication interface for existing users.
- **User Registration** – Registration interface for creating new user accounts.
- **Homepage** – Central navigation interface after successful login.
- **Article Section** – Multiple article modules integrated into the application.
- **GUI-Based Interface** – Interactive desktop interface built with Java.
- **Modular Structure** – Separate packages/classes for login, registration, homepage, and article functionality.
- **Object-Oriented Design** – Demonstrates fundamental Java OOP concepts and modular application development.

## Purpose

This project was developed to demonstrate practical Java programming and GUI development skills while implementing a multi-module desktop application. It focuses on applying OOP concepts, user interaction, interface design, and basic application navigation in Java.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/AlviAdor/tourismo.git
```

2. Open the project in a Java-compatible IDE such as IntelliJ IDEA, Eclipse, or NetBeans.

3. Compile the project.

4. Run `Start.java` to launch the application.
